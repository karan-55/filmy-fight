# Voice clips

Drop audio files here (mp3, m4a, ogg or wav). Name = `character_slot`.

Characters: `bhaiya`, `gussa`, `lucky`, `guru`, `bijli`
Slots:
- `intro`   — round start
- `special` — throw special (Forward + Punch)
- `super`   — super move
- `hit`     — taking a big hit
- `win`     — winning the round
- `ko`      — getting knocked out

Examples: `bhaiya_super.mp3`, `bijli_win.mp3`, `gussa_intro.mp3`

Keep clips short (1–4 seconds) and use only audio you have the rights to publish.
